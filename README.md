# Task Manager Application

A full-stack Task Manager web application built as part of the onboarding curriculum.

## 🚀 Features Completed
- **Add Task:** Create new tasks dynamically from the UI.
- **Display Tasks:** Fetch and list all existing tasks from the database.
- **Delete Task:** Remove completed tasks from the system.
- **Database Integration:** Persistent cloud data storage using MongoDB Atlas / Mongoose.
- **RESTful API:** Structured Express backend routes handling CRUD operations.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+, Fetch API)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas / Mongoose
- **Version Control:** Git, GitHub
